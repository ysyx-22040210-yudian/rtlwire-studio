# RTLWire Studio 0.5.0 界面更新

本版继续使用 Linux 原生 Tk/ttk，适配已验证的 Python 3.6.8、Tk 8.5 和 Verdi O-2018.09-SP2 环境。界面以 Claude 官网的暖色风格为参考，保留 RTLWire 自己的名称和操作结构。

## 外观与交互

- 暖白工作区、石灰色侧栏、陶土橙强调色；绿色、红色、琥珀色分别表示通过、失败和未知。
- 统一圆角按钮、输入框、卡片、页签与对话框内容区。按钮支持悬停、按下、禁用、Tab 焦点、Enter / Space 操作；文本输入保留原生编辑和选择行为。
- 英文品牌与统计数字使用本机可用的衬线字体，中文与工程数据使用清晰的无衬线字体。
- 无额外 Python 依赖。输入框的圆角使用 Tk PhotoImage 的可拉伸边框，兼容不原生支持 PNG 的 Tk 8.5。
- Linux 最外层标题栏及系统窗口边缘由窗口管理器绘制；本工具保留系统的移动、缩放、最大化和关闭行为，不使用无边框窗口替换它们。应用内部的内容面板和对话框卡片由 Tk 绘制为圆角。

## 架构画布

- 用有留白的嵌套容器表达真实父子层次，同级 module 并列，module 卡片有独立标题和轻微阴影。
- “检查层次”标签说明用户选择的范围；实际父层次和检查归属继续分别记录。父范围扣除选中子范围的语义不变。
- 端口落在模块边界，信号标签有独立底色，正交连线的转角平滑；图中每条连接仍绑定原始 NPI 证据。
- 新增“专注画布”：暂时收起输入卡片、统计卡片及对象详情，扩大架构图。点击“返回工作区”或按 Esc 恢复，已输入内容保持不变。默认仍显示用户输入区。
- Tk 和 SVG 使用同一套图形元素，导出保持圆角、配色、文字与信号连接。

## 波形画布

- 隔离、掉电、恢复三个阶段用柔和背景区分；A / B / C / D 边沿、时间刻度和信号名称分开排列。
- 总线用带折角的波形带显示，X 状态使用琥珀色。X 是波形状态，并不直接意味着检查失败；判定结果仍以结果表为准。
- 选中输出口的首次失败位置用红色标记显示，详细时间、实际值和期望值显示在结果说明中。
- 默认 1600×960 窗口可同时完整看到两个控制信号和一个选中输出。窗口高度小于 880 时自动收起统计卡片，把空间留给波形；可通过“展开波形”暂时收起结果表。
- RPT 配置窗口使用圆角内容卡片，可输入独立文件路径和三个关键词，读取预览后应用。

## 验证与示例

0.5.0 已在 Linux 上通过 62 项单元测试、9 项实际 FSDB GUI 流程和 6 项界面验收。
本仓库包含单元测试、独立生成的 FSDB 示例和经过裁剪的历史设计记录；完整开发机日志不属于运行依赖。

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
sh rtlwire-studio --result validation/reach_dual_io
sh rtlwire-studio --result validation/trace_chain
sh rtlwire-studio --result validation/wave_groups_faults
```
